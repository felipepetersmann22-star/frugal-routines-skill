# Frugal Routines

Design and review recurring tasks around when their results are useful.

## Install

Clone this repository into your agent's skills directory, keeping `SKILL.md` and its supporting files together. For Codex:

```sh
git clone https://github.com/felipepetersmann22-star/frugal-routines-skill.git ~/.codex/skills/frugal-routines
```

Restart or refresh skill discovery if needed. Other agents may use a different skills directory.

## Use

Use when creating or reviewing schedules, digests, monitors or reminders. Follow your platform’s own scheduling tools and the owner’s instructions when applying changes.
